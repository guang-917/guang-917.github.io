AI知识｜M2-1 Token 与分词：AI 眼里没有“字”，只有一块块“语义积木”｜25/32

为什么同一段中文，API 扣的钱和自己估的差好几倍？为什么 AI 有时把一个生僻字“念碎”？这期从最底层讲起：模型读你的话之前，一切都被切成叫 token 的积木。

一句话结论

Token 与分词解决的是“AI 到底怎么‘读’你的话”——它不认字、不认词，只认一把把切好的积木；积木的数量直接决定你的 API 账单和上下文容量。

是什么：AI 的“标准件清单”

你发给模型的每句话，第一步不是“理解”，而是被一个叫分词器的程序切成小块，每块就是一个 token。切法不按字、也不按词典，而是按训练语料里的高频搭配切：常见组合整块保留，生僻内容拆成碎片。切完的每块对应字典里的一个编号，模型从头到尾只在这些编号上做运算。

OpenAI 官方文档给过现成例子：英文 "tokenization" 会被切成 "token"+"ization" 两块；"hamburger" 切成 "ham"+"bur"+"ger" 三块；而 "the" 这种高频词只占一块。中文同理——常见字词可能整块，低频组合会被切碎，不同模型的切法还不一样。

为什么重要：token 数 = 钱 + 容量

  • 计费按 token 算：API 输入、输出分开计价，单价都是“每百万 token 多少钱”。估错了 token 数，预算就估错。
  • 上下文窗口按 token 封顶：模型一次能“装下”的对话总长度以 token 计，超了就得裁剪历史或摘要压缩。
  • 英文经验值对中文不适用：官方口径是“英文 1 token ≈ 4 个字符或 0.75 个单词，100 个 token ≈ 75 个单词”，但官方明确写着：这是英语估计，其他语言里字符、词、token 的关系不一样。OpenAI 帮助中心给的硬数字：一句话 "You miss 100% of the shots you don't take" 共 11 个 token；美国《独立宣言》全文约 1,695 个 token。
  • 中文到底多“费”：一份 2026 年 11 月的第三方实测（tiktoken 0.14.0，跑遍 23 篇中文技术文）得出约 0.84 token/字符，也就是 1 个 token 平均覆盖约 1.19 个汉字；同一实测里英文是 1 token ≈ 4.13 字符。结论：给中文估成本，别套英文的“除以 4”，粗估按“1 个字 ≈ 1 个 token”，再用工具实测校准。
生活比方：分词器像乐高积木厂的切件机——不管你递给它的是一栋豪宅模型还是一句诗，它都按自家标准件图，把东西拆成一块块小积木再交给工人。工人（模型）从没见过“整栋房子”，只认积木件号；件号用得越多，工钱越贵、桌面（上下文）越快摆满。

怎么用：三步把 token 用明白

  1. 先数再估：任何要算成本、算容量的场景，用工具数 token，别用字符数换算。
  2. 省 token 省出真金白银：精简提示词（删废话、少堆例子）；长文档先让 AI 压成摘要，再基于摘要做多轮对话。
  3. 重复内容走缓存：系统提示词、固定背景说明这类每轮都相同的前缀，命中缓存后计费更低（OpenAI 帮助中心说明 cached tokens 常按较低费率计）。稳定内容放前面，可变内容放后面，缓存才命中。

今天就能用

打开 OpenAI 官方 Tokenizer 工具（platform.openai.com/tokenizer），把你最常用的那段中文提示词粘进去，看两件事：① 它把哪些词切成了碎块？② 总共多少 token？想批量化，就在本机装 OpenAI 开源的 tiktoken 分词库（pip install tiktoken），用 tiktoken.encoding_for_model(模型名) 精确计数。验证方法：同一段 200 字内容，中文、英文各贴一次，亲眼看 token 数差多少——这个差距就是你的账单差距。

政策/行业动态

美国把出口管制延伸到“远程租算力”：美国商务部工业与安全局（BIS）2026 年 11 月 15/16 日发布《应对先进半导体远程访问的临时最终规则》，定于 11 月 19 日在《联邦公报》刊登并当日生效。核心两条：全球任何数据中心，若向总部位于中国、中国澳门及其他 D:5 组地区的企业提供超过 1200 万 TPP（总处理性能）的算力，相关芯片出口须申请许可，已有安排给约 90 天过渡期（按 11 月 19 日生效算约至 2027 年 2 月 17 日）；印尼、马来西亚、新加坡、泰国、巴西新纳入先进芯片许可要求。规则同时正式废止此前的“AI 扩散规则”。11 月 17 日，中国外交部发言人郭嘉昆回应称此举是“典型的经济胁迫和长臂管辖”，中方将采取必要措施维护正当权益。对普通人的意味：个人日常用 AI 短期无直接影响；但用境外云算力做训练或推理的从业者，需立刻核查供应链与客户结构的合规性，境外算力租赁的价格和可得性可能出现波动。
